01Installation

Which file do I need?

Windows

Use Microsoft Store for installation and Store updates, or choose the .exe installer. The .msi package is an alternative Windows installer.

macOS

Choose Apple Silicon for M-series chips, or Intel for Intel Macs. Open the .dmg and drag OpenDoc into Applications.

Linux

Use .deb for Debian/Ubuntu, .rpm for RPM-based distributions, or the native package for Arch Linux. AppImage is a portable option; give it permission to run before opening it.

Updates

Check for updates in Settings → General. Microsoft Store manages its own updates. Native Linux packages (.deb, .rpm, Arch) are updated from GitHub releases.

02First steps

Add your library.

Already use Dash or Zeal? Select your existing docsets folder in Settings. Starting fresh? Open the catalog and download the documentation you need while online. Installed docsets are available offline.

Ctrl K / ⌘ K — open search.

OpenDoc does not bundle or redistribute proprietary docsets.
