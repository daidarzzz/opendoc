Features

Everything you need,
nothing you don't

Built with Tauri and Rust for native performance. Designed to get out of your way and let you focus on what matters.

⚡

Lightning Fast

In-memory fuzzy search returns results in ~37ms across 300,000 entries. Exact match, prefix, and fuzzy ranking — instantly.

🎨

Beautiful UI

Clean, modern interface with dark and light themes, 4 accent colors, and a command palette inspired by VS Code and Obsidian.

📚

Docset Compatible

Works with existing Dash and Zeal docsets. Standard and Core Data indexes, tarix format fully supported.

🔒

Fully Offline

All your documentation lives on your machine. No internet required, no tracking, no telemetry, no ads. Ever.

🪶

Lightweight

~10–15 MB installer, under 80 MB RAM. Built with Tauri + Rust for native performance without the bloat.

🖥️

Cross-Platform

Available for Windows, macOS (Apple Silicon & Intel) and Linux. Same experience everywhere.
